# Интеллектуальные системы — Лабораторные работы 0–5

- **Лаб_0**: Базовый пайплайн обучения и подбора гиперпараметров (MLflow + Optuna).
- **lr1_local**: Развёртывание LLM как сервиса (vLLM / llama.cpp), измерение TTFT, TPOT, Prefix Caching и SLA (Otchet_LR1.docx).
- **lr2_local**: Базовый RAG на корпусе SciFact (BAAI/bge-small-en-v1.5 + Qwen3-4B-Instruct, JSON Schema) (Otchet_LR2_Final.docx).
- **lr3_local**: Улучшение поиска в RAG: BM25, RRF, Cross-Encoder (ms-marco-MiniLM-L6-v2) и проверка на holdout (Otchet_LR3_Final.docx).
- **lr4_local**: Собственная обвязка агента (Agent Harness) на стенде AgentDojo v1.2.2 (ReAct vs Plan-then-execute) (Otchet_LR4_Final.docx).

- **lr5_local**: Оценка агента ReAct: стабильность (pass^k и pass@k), внедрение сбоев FaultyRuntime (политики P0–P2).
